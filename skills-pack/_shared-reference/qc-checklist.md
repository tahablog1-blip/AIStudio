# قائمة مراقبة الجودة

## الصورة
- لا توجد إطارات سوداء/بيضاء غير مقصودة أو تجمدات أو وميض.
- لا توجد قفزات غير مقصودة في التعريض أو توازن الأبيض أو اللون.
- التركيز والقص والتكوين والنصوص واضحة.
- لا توجد حواف keying أو roto أو compositing ظاهرة بشكل غير مقصود.
- النصوص داخل safe areas ومقروءة.

## الصوت
- الحوار مفهوم ومتوازن.
- لا يوجد clipping أو ضجيج مزعج أو انقطاع.
- الموسيقى والمؤثرات لا تطغى على الحوار.
- الصوت متزامن مع الصورة.
- نهاية وبداية الصوت نظيفتان.

## المحتوى
- الأسماء والأرقام والحقائق صحيحة وفق المصادر المقدمة.
- الترجمة متزامنة وخالية من أخطاء ظاهرة.
- لا يوجد اقتطاع يغيّر معنى الكلام.
- حقوق المواد والموسيقى والخطوط والأصول موثقة حسب المتاح.

## التسليم
- الملف يفتح ويعمل.
- المدة والأبعاد ومعدل الإطارات والترميز مطابقة للمطلوب.
- أسماء الملفات والإصدارات واضحة.
- ملفات المصدر والأصول المطلوبة موجودة.
- تقرير QC يذكر أي قيود لم تُحل.
