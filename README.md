# 🎬 AI Studio — استوديو إنتاج مرئي يعمل بالذكاء الاصطناعي

استوديو فيه **31 موظفاً**، وكل موظف ليه ملف وصلاحيات ومهارات **بتنفّذ فعلاً**: بتعمل مونتاج، وألوان، وصوت، وموشن، و3D، ومؤثرات، وتصدير، وفحص جودة، وبتطلّع ملفات حقيقية. كمان فيه **منسّق مركزي** بيوزّع المهام ويشغّلها بالتوازي، وبيعيد المحاولة لو حاجة فشلت، وبيحتفظ بكل إصدار.

## المكونات
| المسار | المحتوى |

## الاستخدام
### 1. كمشروع في Claude Code
افتح فولدر `AIStudio` في Claude Code، وابعت طلبك:
> «اعملّي إعلان 30 ثانية لمنتجي من الفيديوهات دي…»

المدير التنفيذي (`executive-producer`) هيستلم الطلب، وهيعمل المشروع ويوزّع المهام. وتقدر تنادي أي موظف بالاسم، زي `colorist` أو `sound-engineer` أو `motion-designer`…

### 2. كـ Plugin
```
/plugin install /path/to/AIStudio
```

### 3. من سطر الأوامر مباشرة
```bash
pip install -r requirements.txt
python -m studio new "إعلان" --raw clip1.mp4 clip2.mp4 logo.png script.md
python -m studio plan إعلان promo --params '{"footage":["clip1.mp4","clip2.mp4"],"script":"script.md","logo":"logo.png","brand":"X","tagline":"..."}'
python -m studio run إعلان
python -m studio status إعلان
```
أو استخدم أداة واحدة مباشرة، بصلاحيات موظف معيّن:
```bash
python -m studio do color.grade --role color-grader --args '{"src":"a.mp4","out_dir":"out","look":"film"}'
```

## نظام العمل الجماعي
1. **المدير التنفيذي** بيستلم الطلب ويعمل المشروع (`new`).
2. **المخرج الإبداعي** بيحلل المتطلبات ويكتب دليل الأسلوب.
3. **السيناريو وقائمة اللقطات والستوري بورد** (`plan`).
4. **التوزيع:** كل مهمة ليها موظف، واعتماديات، وصلاحيات بتتفحص (`validate`).
5. **التنفيذ المتوازي** (`run --workers N`).
6. **تبادل الملفات:** كل موظف بيستلم مخرجات اللي قبله بالإشارة لها (`{task:id}`)، وفيه **لوحة رسائل** (`post` / `inbox`).
7. **المونتير الرئيسي** بيجمّع المشروع.
8. **الألوان والصوت والمؤثرات** بيعملوا المعالجة النهائية.
9. **مراقب الجودة** بيفحص، ولو فيه فشل بيتوقف التسليم.
10. **المدير التنفيذي** بيعتمد (`project.deliver`).
11. **التسليم** في `deliver/`: فيديوهات المنصات، والصور المصغّرة، ومشروع Premiere/Resolve، وتقرير الجودة.

**بيدعم كمان:** متابعة نسبة الإنجاز، واكتشاف التعارض (حلقات الاعتماد، والكتابة على نفس الملف، والصلاحيات)، وإعادة المحاولة تلقائياً، وحجب المهام التابعة لو مهمة فشلت، وإعادة تشغيل يدوية (`retry`)، وبوابات مراجعة (`review`)، والاحتفاظ بكل الإصدارات (`work/<task>/v001…`).
