## الأقسام (7)
| القسم | الموظفون |
|---|---|
| الإدارة | المدير التنفيذي، المخرج الإبداعي، مدير الإنتاج |
| ما قبل الإنتاج والإخراج | المخرج السينمائي، مدير التصوير، كاتب السيناريو، الستوري بورد |
| المونتاج | الرئيسي + 8 متخصصين |
| الجرافيك والمؤثرات | VFX، الموشن، الأنيميشن، التركيب، التتبع، المقدمات، الأغلفة |
| الألوان | التصحيح، المعالجة السينمائية |
| الصوت | مهندس الصوت، مصمم المؤثرات، التعليق الصوتي |
| التسليم والجودة | تحسين الجودة، الضغط والتصدير، مراقب الجودة |

## الصلاحيات (بتتطبق بالكود، مش بالكلام)
- **حدود التنفيذ:** كل موظف له قائمة `modules` في `studio/roles.py`. المنسّق (`orchestrator.validate`) بيرفض المهمة قبل التشغيل لو الموظف المسند ليه مش مخوّل بالأداة. ونفس القاعدة في `studio do --role`.
- **بوابات المراجعة:** أي مهمة فيها `review_by` بتقف عند حالة `needs_review` لحد ما المراجع المحدد يعتمدها: `studio review ... --by <role>`. ومحدش غير المراجع (أو المدير التنفيذي) يقدر يعتمد.
- **بوابة الجودة:** أي أداة بترجع `qc_pass: false` بتفشّل المهمة، فالمهام اللي بعدها بتتحجب تلقائياً ومش بيحصل تسليم.
- **الاعتماد النهائي** والنقل لـ `deliver/` من صلاحية `executive-producer` بس (`project.deliver`).
